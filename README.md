# homebrew-futurlang

Homebrew tap for [FuturLang](https://github.com/WenitteApiou/futurlang) — a proof-oriented programming language.

## Install

```bash
brew tap WenitteApiou/futurlang
brew install futurlang
```

## Usage

```bash
fl <file.fl>           # run a .fl file
fl check <file.fl>     # verify proof structure
fl build <file.fl>     # compile to Rust / binary
fl create-app <name>   # scaffold a new FL app
```
